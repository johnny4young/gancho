# Gancho v0.8.3 — Pro activation that can move with you

Gancho 0.8.3 opens the direct-download Pro path for the first time. A purchase
can be activated without a private signing key in the app, remains useful
through ordinary offline stretches, and can release its activation when you
move to another Mac.

## Highlights

- **Buy and activate Pro from the direct download.** Gancho opens the Lemon
  Squeezy checkout, accepts the issued license key, and stores only the
  activation record needed to restore the entitlement. No license-signing or
  payments secret ships in the app, and activation only accepts keys issued
  for the Gancho Pro product itself — a valid key for someone else's Lemon
  Squeezy product, or a test-mode key, unlocks nothing.
- **Keep working offline.** Gancho periodically re-confirms the activation and
  keeps Pro available for up to 30 days when the service cannot be reached. An
  unknown or malformed response cannot revoke Pro; only an explicit denial can.
- **Move a license between Macs.** Settings → Pro can deactivate the current
  Mac and release its slot without deleting the encrypted history stored there.
- **Use encrypted iCloud sync as an eligible Pro install.** The signed direct
  build carries the production CloudKit profile, and the release is cut only
  after its production schema and signed two-Mac candidate matrix pass.
- **Clips remember which device they were copied on.** New captures are
  stamped with the capturing device's name, the name travels with the clip
  when sync is enabled, and the iPhone clip detail shows it. Clips captured
  before this release carry no origin.

## Install or update

- Download the signed and notarized
  [Gancho 0.8.3 DMG](https://github.com/johnny4young/gancho/releases/download/v0.8.3/Gancho-0.8.3.dmg),
  or install the Mac app plus its bundled `gancho` CLI with Homebrew:

  ```bash
  brew tap johnny4young/tap
  brew install --cask gancho
  ```

- Existing direct-download installs receive v0.8.3 through the signed Sparkle
  feed. You can also choose **Settings → General → Check for Updates…**.
- The release assets include `Gancho-0.8.3.dmg.sha256` for independent checksum
  verification.

Gancho requires macOS 26 or later. The iPhone and iPad targets require iOS 26
or later and are not distributed by the DMG or Homebrew cask.

## Availability

Local history remains free. Pro is a separate direct purchase and unlocks the
documented higher limits, on-device intelligence, and encrypted iCloud sync.
The App Store and TestFlight channels remain in preparation.

## Release verification

The published DMG ships with a SHA-256 sidecar that pins the exact bytes; the
Homebrew cask is generated from that same checksum. Automated release QA
verifies the Developer ID signature, hardened runtime, notarization and
stapling, Gatekeeper acceptance, embedded production profile, signed CloudKit
and Push entitlements, absence of private licensing secrets, checksum sidecar,
and signed Sparkle appcast. Before the tag is pushed, the same signed candidate
must pass clean activation plus create, edit, board membership, deletion,
offline recovery, retention, and relaunch convergence on two Macs using the
same Apple Account.
