# Gancho v0.8.3 — Copy from images and reuse your clipboard

> Cross-device and oldest-supported-runtime acceptance remain pending. See
> Release verification and Known limitations before using sync with important data.

Gancho 0.8.3 opens the direct-download Pro path for the first time. A purchase
can be activated without a private signing key in the app, remains useful
through ordinary offline stretches, and can release its activation when you
move to another Mac.

## Highlights

- **Copy text from saved images for free.** Run local OCR without enabling
  automatic indexing, review or edit the result, and save it only when requested.
  The inline image preview offers recognized lines and safe link/email actions.
- **Copy text from a screen region.** Press Control–Option–T, select with the
  Fusion hook-and-crosshair cursor, then paste manually. A newer clipboard value
  is preserved; Private Mode cancels pending work. No screenshot or clip is saved
  automatically. Automatic searchable-image indexing remains Pro.
- **Recognize clips in the Library.** Lazy image thumbnails, color swatches and
  code previews make browsing visual while protected content remains masked.
- **Save recurring filters locally.** Reapply named searches with type, source
  application, board and pinned-only predicates; definitions stay in the encrypted
  local store and are not synced.
- **Copy several text clips together.** Review their visible order, reorder them
  and choose a separator before copying. This does not create a clip or replace
  PasteStack's sequential behavior.

- **The source now targets macOS 15.4 (Sequoia).** Capture, encrypted history,
  search, boards, retention, sync, Pro and updates are intended to work below
  macOS 26. The signed candidate still needs the oldest-supported-runtime
  acceptance matrix before publication; a deployment target alone is not that
  evidence. The Foundation Models tier requires macOS 26: below it, clip titles fall
  back to the deterministic heuristics and model-backed Smart Paste rewrites,
  Translate, and Ask your clipboard are unavailable — exactly as when Apple
  Intelligence is switched off. Deterministic PII redaction keeps working
  everywhere, the Intelligence screen states the requirement plainly, and the
  interface uses an opaque material where Liquid Glass does not exist.
- **Buy and activate Pro from the direct download.** Gancho opens the Lemon
  Squeezy checkout, accepts the issued license key, and stores only the
  activation record needed to restore the entitlement. No license-signing or
  payments secret ships in the app, and activation only accepts keys issued
  for the Gancho Pro product itself — a valid key for someone else's Lemon
  Squeezy product, or a test-mode key, unlocks nothing.
- **Keep working offline.** Gancho periodically re-confirms the activation and
  keeps Pro available for up to 30 days when the service cannot be reached. An
  unknown or malformed response cannot revoke Pro; only an explicit denial can.
- **Move a license between Macs.** Settings → Pro can deactivate the current
  Mac and release its slot without deleting the encrypted history stored there.
- **Use encrypted iCloud sync as an eligible Pro install.** The direct
  artifact requires a production CloudKit profile. Cross-device convergence and
  the current Production schema still need the post-release matrix below.
- **Clips remember which device they were copied on.** New captures are
  stamped with the capturing device's name, the name travels with the clip
  when sync is enabled, and the iPhone clip detail shows it. Clips captured
  before this release carry no origin.

## Also improved

- **Translate uses Apple's Translation engine for installed language pairs.**
  That is noticeably faster than the on-device model once it is warm; every
  other pair still falls back to the model. Both paths redact secrets first,
  and Gancho never downloads language assets on its own.
- **Large histories do less work.** Lists stop loading clip bodies they never
  show, finding source apps uses an index instead of a full scan, semantic
  search reads stored vectors in place, and incoming sync changes commit once
  per page. Semantic search and applying a sync page each measured about twice
  as fast in testing.
- **A burst of copies no longer starts a model session per clip.** On-device
  enrichment runs at most two clips at a time, in the order you copied them.

## Also fixed

- A Lemon Squeezy outage, rate limit, or gateway error can no longer revoke an
  activated license — only a decodable answer that explicitly denies the key
  does. Deactivating a Mac whose slot was already released from the dashboard
  now reports a clean release instead of a false network error.
- Backups are safer end to end: export refuses to write an archive with a
  corrupt payload and says so, and restore verifies the bytes it imports
  instead of trusting the archive's own manifest.
- With iCloud sync on, a delete that fails on this Mac is no longer sent to
  your other devices, so a clip can no longer vanish everywhere else while
  surviving here. The failure is reported instead.
- Exporting settings, saving a support bundle, changing MCP access, buying or
  restoring Pro, turning off Remember searches, and editing a snippet now say
  so when the write fails instead of looking like they worked.
- Settings, Welcome, Privacy Center, MCP Access, and Gancho's other windows
  open centered, so none of them sits partly off-screen on a narrow display.
- Sparkle 2.9.6 hardens the update installer.

## Install or update

Download the signed DMG and its SHA-256 sidecar from this release's assets.
Compare the downloaded bytes with the sidecar before installing. Existing direct
installs can use the signed Sparkle update; Homebrew's cask follows the published
artifact. If assets or the update feed are not available yet, publication is not
complete—do not substitute an older candidate from another source.

Gancho requires macOS 15.4 or later; the on-device model tier additionally
requires macOS 26. The iPhone and iPad targets require iOS 26 or later and are
not distributed by the DMG or Homebrew cask.

## Availability

Local history remains free. Pro is a separate direct purchase and unlocks the
documented higher limits, on-device intelligence, and encrypted iCloud sync.
The App Store and TestFlight channels remain in preparation.

## Release verification

The release workflow must pass lint, unit tests and both app builds before
packaging. Publication requires Developer ID signing, hardened runtime,
notarization/stapling, Gatekeeper acceptance, the production CloudKit/Push profile,
a SHA-256 sidecar and an EdDSA-signed Sparkle appcast. Inspect the successful
workflow for the exact tag; these automated checks do not certify physical-device
behavior. A packaging input tripwire alone is not a scan of bundle contents.

The signed two-Mac matrix is deliberately deferred until after publication for
this early release. Clean activation, production schema compatibility, capture,
edit/delete, board membership, retention, offline recovery and relaunch convergence
must be tested using the released bytes. Real Sequoia, VoiceOver and screen-OCR
permission/compositor/display checks also remain pending. Keep backups and use
synthetic or disposable data for that validation.

## Known limitations

- A background history refresh can reset the panel selection; confirm the
  highlighted clip before pressing Enter.
- Save snippet body edits explicitly before changing Library selection. Draft
  behavior during navigation or sync refresh remains under investigation.
- A hosted iOS board-editor dismissal wait failed once and passed unchanged on
  retry; macOS hosted UI has three signing/menu-bar environment skips. Neither
  is claimed as completed real-device acceptance.
- This DMG distributes macOS only. iPhone/iPad installation requires a separate
  distribution path; App Store and TestFlight availability is not implied.
