# Gancho v0.10.2 — Clips sealed under an old key, repaired

Gancho 0.10.2 is a maintenance release that fixes the cause behind the stuck
sync error 0.10.1 worked around. After an earlier store reset, an image or file
could be left on disk encrypted with a key the current store no longer has.
Copying the same bytes again reused that file, so the new clip could not be
pasted or synced. This release repairs those files where it can and lets you
remove the ones it can't.

## Highlights

- **Copying again repairs the file.** When a copy finds the same image or file
  stored under an earlier key, Gancho re-encrypts it under the current key, so
  the clip can be pasted and synced again.
- **iCloud restores synced clips.** When sync starts, Gancho fetches the iCloud
  copy of synced clips whose local content was sealed under an earlier key,
  which rewrites that content under the current key.
- **The Privacy Center counts what's left.** A new **Unreadable clips** section
  counts clips this device can't open, separating synced clips iCloud couldn't
  restore. You can remove them from this device only; iCloud and your other
  devices aren't touched, and no deletion is synced.
- **A check that stays cheap.** The first count opens every stored image and
  file once; after that only the clips it flagged are rechecked. A check that
  fails is recorded in Recent issues instead of showing none.

[changelog](https://github.com/johnny4young/gancho/blob/main/CHANGELOG.md)

## Install or update

Download the [signed DMG](https://github.com/johnny4young/gancho/releases/download/v0.10.2/Gancho-0.10.2.dmg)
and its [SHA-256 sidecar](https://github.com/johnny4young/gancho/releases/download/v0.10.2/Gancho-0.10.2.dmg.sha256).
Compare the downloaded bytes with the sidecar before installing. Existing direct
installs can use the signed Sparkle update; Homebrew's cask follows the published
artifact. If assets or the update feed are not available yet, publication is not
complete—do not substitute an older candidate from another source.

Gancho requires macOS 15.4 or later; the on-device model tier, translation
with installed languages and Liquid Glass additionally require macOS 26. The
iPhone and iPad targets require iOS 26 or later and are not distributed by the
DMG or Homebrew cask.

## Known limitations

- A clip that was never synced and whose content was sealed under a lost key
  cannot be recovered; the Privacy Center offers to remove it.
- A synced clip whose iCloud copy has no content, or that iCloud no longer
  has, stays unreadable and is counted separately.
- Text recognized in images (OCR) stays on the Mac that recognized it; it is
  not synced to your other devices.
- Backups made with Settings › General › Back up history… do not include
  boards, board membership or text recipes yet, and recipes are never synced.
- This DMG distributes macOS only. iPhone/iPad installation requires a separate
  distribution path; App Store and TestFlight availability is not implied.
