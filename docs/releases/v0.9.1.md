# Gancho v0.9.1 — The panel's text size, for real

Gancho 0.9.1 is a maintenance release. Settings › Panel › Text size now
changes the panel. In v0.9.0 and every version since the preference first
shipped in 0.8.0, Small, Standard and Large rendered identically, because the
setting was wired to a mechanism macOS does not honour. This release also
makes two sync failures leave a trace instead of passing silently.

## Highlights

- **A text size you can see.** The panel's rows, toolbar chips, peek, action
  dock and footer grow or shrink with the preference. Each style starts from
  the size macOS reports for it and is scaled by the preference, so the
  hierarchy between titles, body text and captions stays the same.
- **iPhone and iPad keep following the system.** History rows share their
  view with the Mac panel; they keep respecting the iOS text size (Dynamic
  Type).
- **Sync failures are no longer silent.** Saved sync state that can no longer
  be read now leaves a content-free entry in the Privacy Center's Recent
  issues before a fresh fetch starts, and a restart that fails after the
  iCloud account changes is recorded instead of dropped.

See the complete
[changelog](https://github.com/johnny4young/gancho/blob/main/CHANGELOG.md)
for all changes and fixes, including those in the iPhone and iPad apps, which
this release does not distribute.

## Install or update

Download the [signed DMG](https://github.com/johnny4young/gancho/releases/download/v0.9.1/Gancho-0.9.1.dmg)
and its [SHA-256 sidecar](https://github.com/johnny4young/gancho/releases/download/v0.9.1/Gancho-0.9.1.dmg.sha256).
Compare the downloaded bytes with the sidecar before installing. Existing direct
installs can use the signed Sparkle update; Homebrew's cask follows the published
artifact. If assets or the update feed are not available yet, publication is not
complete—do not substitute an older candidate from another source.

Gancho requires macOS 15.4 or later; the on-device model tier and Liquid Glass
additionally require macOS 26. The iPhone and iPad targets require iOS 26 or
later and are not distributed by the DMG or Homebrew cask.

## Availability

Local history remains free. Pro is a separate direct purchase and unlocks the
documented higher limits, on-device intelligence, and encrypted iCloud sync.
The App Store and TestFlight channels remain in preparation.

## Known limitations

- Typing a search and pressing Enter before the list refreshes pastes the
  previously highlighted clip; wait for the results to update first.
- A snippet deleted on another device while you are editing it closes the
  editor and drops the unsaved draft.
- This DMG distributes macOS only. iPhone/iPad installation requires a separate
  distribution path; App Store and TestFlight availability is not implied.
