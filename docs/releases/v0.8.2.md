# Gancho v0.8.2 — a panel that never dead-ends, in your language

Gancho 0.8.2 is a maintenance release. It removes a filtered dead end in the
history panel, finishes translating the strings an automated check could not
see, and refreshes the encrypted storage and input dependencies.

## Highlights

- **A filter that finds nothing no longer looks like an empty history.**
  Narrowing to a kind, board, or source app without typing a search used to show
  the first-run message — claiming your history was empty when it was not — and
  offered no way back. That state now reports no matches and keeps **Clear
  filters** reachable, including for VoiceOver, which previously could not focus
  the button at all.
- **Spanish covers the copy that slipped past the checker.** Four strings still
  rendered in English: the paste stack's VoiceOver label on Mac, and the Share
  action, the copy-last-URL confirmation, and the clear-sensitive-clips result on
  iPhone and iPad. The localization gate now reads interpolated copy and strings
  declared directly as localized keys, so this class of gap fails a test instead
  of reaching a release.
- **Refreshed foundations.** The encrypted storage stack moves to GRDB 7.11.1
  and SQLCipher.swift 4.17.0 with no change to the database schema or encrypted
  store format. Global shortcuts move to KeyboardShortcuts 3.0.1 with stored
  shortcuts preserved, and Sauce 2.5.2 corrects keypad Enter mapping while
  layout-aware paste-back behaves as before.

Internally, the macOS history panel was split by responsibility — capture
status, preview session, selection actions, results rendering, and the modal
layer now live in focused, separately tested pieces — with no change to
navigation, keyboard semantics, or paging.

See the complete
[changelog](https://github.com/johnny4young/gancho/blob/v0.8.2/CHANGELOG.md#082---2026-07-25)
for all changes and fixes.

## Install or update

- Download the signed and notarized
  [Gancho 0.8.2 DMG](https://github.com/johnny4young/gancho/releases/download/v0.8.2/Gancho-0.8.2.dmg),
  or install the Mac app plus its bundled `gancho` CLI with Homebrew:

  ```bash
  brew tap johnny4young/tap
  brew install --cask gancho
  ```

- Existing direct-download installs receive v0.8.2 through the signed Sparkle
  feed. You can also choose **Settings → General → Check for Updates…**.
- The release assets include `Gancho-0.8.2.dmg.sha256` for independent checksum
  verification.

Gancho requires macOS 26 or later. The iPhone and iPad targets require iOS 26
or later and are not distributed by the DMG or Homebrew cask.

## Availability

The direct-download app is signed with a production CloudKit and Push profile,
so the artifact is technically sync-capable. A fresh public install currently
runs as the Free tier and remains local-only because cross-device sync requires
Pro and secure direct-download activation is not yet available. Local encrypted
history persists across app updates.

## Release verification

The published DMG ships with a `Gancho-0.8.2.dmg.sha256` sidecar that pins the
exact bytes; the Homebrew cask is generated from that same checksum, so both
channels resolve to one artifact. Automated release QA verifies the Developer ID
signature, hardened runtime, notarization and stapling, Gatekeeper acceptance,
embedded production profile, signed CloudKit and Push entitlements, checksum
sidecar, and signed Sparkle appcast before anything is published. Manual
clean-install, upgrade, and two-device sync exercises are tracked separately and
are not claimed by this verification result.
