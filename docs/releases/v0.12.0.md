# Gancho v0.12.0 — A new look, and a lighter Mac app

Gancho 0.12.0 redraws the whole app around one idea: a calm graphite interface
where a single lime accent marks what Return does. The Mac history panel, the
Library, Settings, the menu bar and iPhone share the new look, and the Mac app
does a fraction of the work it did on every copy.

## Highlights

- **One accent, one meaning.** The interface is neutral graphite with
  Gancho's own typefaces (Instrument Serif, Geist and Geist Mono). Lime marks
  only what Return does: the selected row's key and the preview's main verb.
  Blue, indigo and orange are gone; red is left for errors, Delete, access
  denied and a secret's last minute.
- **Rows that show the clip.** A link leads with its site, a color is its
  swatch, code keeps its typeface, an image is its thumbnail, and a secret is
  its mask inside a ring that counts down the time it has left.
- **⌘K for everything a clip can do.** One action panel holds the clip's verbs
  with their keys, its transforms, recipes and Smart paste behind one filter.
  It floats over the preview and opens while a transform runs. ⌘T still opens
  it.
- **A preview that says what will paste.** A link names its scheme, host, path,
  query and fragment, decodes each parameter, and lists what Return, ⌥Return
  and the Markdown link paste. The actions are one line: Paste as the only
  filled button, then Plain, Pin, Board and Stack with their keys.
- **Time and privacy you can read.** A secret counts down on a dial with minute
  marks, and Private Mode shows its time left on the same ring and draws hidden
  rows as bars and hatch.
- **States that teach the next key.** An empty history shows the three keys of
  the whole loop. A search that finds nothing offers what the other modes found,
  one ↓ away, with the matches underlined. The footer only lists keys that work
  right now.
- **The paste stack in the preview.** Numbered clips, the pasted ones checked
  and the next one marked; Return pastes the next and esc ends the run.
- **The Library as a wall of clips.** Each board shows its clips at their own
  shapes under its name, its count and a bar of the kinds it holds, with a
  full-height sidebar.
- **iPhone in the same language.** Home lists clips as touch-size rows on
  graphite, and a color or an image fills the top of its clip with each format
  one tap to copy.
- **Lighter on every copy.** Titles, search and board suggestions share one
  loaded language model, and the hidden panel no longer redraws on every copy.
  On a busy Mac (Debug builds, 20 copies, indicative figures) each copy went
  from about 295 to 46 ms of processor time and memory after the burst from
  about 121 to 64 MB; at rest a Release build went from about 7 to 1.3 ms of
  processor time per second.

It also closes two capture windows around a pause or a screen share, keeps
shortcuts working while a Gancho menu is open, preserves query escaping when
removing URL trackers, and recognizes every kind of line ending in the
developer line actions. See the complete
[changelog](https://github.com/johnny4young/gancho/blob/main/CHANGELOG.md)
for all changes and fixes.

## Before you update

- **Same requirements as 0.11.** Gancho still needs macOS 26 on Apple Silicon.
- **Nothing to migrate.** This release changes no database schema and no
  CloudKit field.
- **Your shortcuts stay.** ⌘T opens the new action panel, and every recorded
  shortcut keeps its key.

## Install or update

Download the [signed DMG](https://github.com/johnny4young/gancho/releases/download/v0.12.0/Gancho-0.12.0.dmg)
and its [SHA-256 sidecar](https://github.com/johnny4young/gancho/releases/download/v0.12.0/Gancho-0.12.0.dmg.sha256).
Compare the downloaded bytes with the sidecar before installing. Existing direct
installs can use the signed Sparkle update; Homebrew's cask follows the published
artifact. If assets or the update feed are not available yet, publication is not
complete—do not substitute an older candidate from another source.

Gancho requires macOS 26 or later on Apple Silicon. The iPhone and iPad targets
require iOS 26 or later and are not distributed by the DMG or Homebrew cask.

## Availability

Local history remains free. Pro is a separate direct purchase and unlocks the
documented higher limits, on-device intelligence, and encrypted iCloud sync.
The App Store and TestFlight channels remain in preparation.

## Release verification

This note describes a prepared candidate; v0.12.0 is not published until the
tagged release workflow completes and this section records the published
commit, build number, workflow run and DMG checksum.

The release workflow must pass lint, unit tests and both app builds before
packaging. Publication requires Developer ID signing, hardened runtime,
notarization/stapling, Gatekeeper acceptance, the production CloudKit/Push
profile, a SHA-256 sidecar and an EdDSA-signed Sparkle appcast. These automated
checks do not certify physical-device behavior.

This release changes no CloudKit field and no database schema. The signed
two-Mac matrix, VoiceOver, screen-OCR permission/display checks and real iPhone
and iPad acceptance remain pending; run them on the released bytes with synthetic
or disposable data and keep backups.

## Known limitations

- The Compact panel size opens at 492 pt tall, not 480, because the panel's
  content needs that height.
- A clip made with Merge double copies is plain text, so it loses any formatting.
- Image peeks show no scroll bar; the wheel and the trackpad still scroll them.
- Text recognized in images (OCR) stays on the Mac that recognized it; it is
  not synced to your other devices.
- Backups made with Settings › General › Back up history… do not include
  boards, board membership or text recipes yet, and recipes are never synced.
- This DMG distributes macOS only. iPhone/iPad installation requires a separate
  distribution path; App Store and TestFlight availability is not implied.
